## 二、裁切策略（1664x928 横图 → 正方形）

源图是 **1664x928 横向矩形**，Android launcher 图标必须正方形，故采用**居中裁切**：

```
源图       1664 x 928
取短边     928
裁切偏移   左 368px，上 0px      -> 左右各切 368px，上下不切
结果       928 x 928 正方形
再 LANCZOS 等比缩放到各目标尺寸
```

- 中间产物：`/root/workspace/analysis/e13_assets/derived/app_icon_square_928.png`
- 中间产物 md5：`a871959a0fa2807698a2a4a824d00351`

> **风险声明**：这是**盲切**。我无法看图，**无法判断左右各 368px 是否切掉了图形主体的关键部分**。
> 若人工目视发现被切，补救方向是改为「等比缩放 + 补背景色」，需确认后重跑本流程。

关于页 Logo **不裁方**：横图，组件以 `w-44`（约 176 CSS px）按原始比例显示。

## 四、代码改动（关于页 Logo）

### 改了什么

**只改了 `src/components/ui/DeepStudentLogo.tsx` 一个文件。`AboutTab.tsx` 未被我改动。**

原实现：`DeepStudentLogo` 是**内联 SVG wordmark**（`viewBox="0 0 409 147"`，含十余条 `<path>`）。

新实现：SVG 外壳保留（`viewBox` / `role="img"` / `aria-labelledby` 不变），内部图形替换为 `<image href="/ai-study-logo-832.png">`，并按原始比例铺满 viewBox。

同时保留一个**有实际作用**的语义令牌承载层：`<rect className="fill-background stroke-foreground/15">` 作为底板与描边 —— 位图自身不随主题变色，这层保证浅色/深色模式下 logo 都有可辨识边界。

`DeepStudentMark`（方形标，被 `StatusBar.tsx` 使用）**完全未改动**，不在本次需求范围内。

### 为什么不动 AboutTab.tsx

`AboutTab.tsx:7` 的 import 与 `:127` 的 `<DeepStudentLogo className="w-44 max-w-full" />` 引用**完全不需要改** —— 组件名和 props 接口未变，替换发生在组件内部。

该文件当前被 task-7 / task-9 占用（实测其 `M` 改动是第 381 行平台文案 `Windows / macOS / iPadOS / Android` → `Android`，与 Logo 引用无关，**无冲突**）。

### 组件 props 兼容性

`DeepStudentLogo` 的对外接口未变：`{ className?: string; title?: string }`。所有既有调用点无需修改。
