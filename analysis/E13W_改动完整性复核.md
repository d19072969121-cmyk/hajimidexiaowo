## 4. JSON 合法性与 zh/en 对称性

**JSON 合法性**：`src/locales/**/*.json` 共 **90 个文件全部 `json.load` 成功，零失败**。

**对称性**：逐文件比对叶键集合，45 个文件中 **44 个完全对称**，唯一不对称：

```
mindmap.json   zh 504 叶键 / en 511 叶键   仅zh 7 / 仅en 14
```

明细（**结构性，非丢键**）：zh 侧 7 个裸计数键，en 侧对应 14 个带复数后缀的键：

```
import.imagePlaceholderNote          → _one / _other
recite.blankBranchDone               → _one / _other
recite.clearBranchBlanksDone         → _one / _other
recite.remaining                     → _one / _other
shellV2.clipboard.copiedNodes        → _one / _other
shellV2.clipboard.cutNodes           → _one / _other
shellV2.versions.nodeCount           → _one / _other
```

en 用的是 i18next v4 复数后缀形式，zh 无复数规则故只保留基础键 —— 属**既有的语言约定**，两边都能正常渲染，不是覆盖或丢失（`settings.json` 本身也用了同一模式：`auto_fetch_models_empty` 无 `_one/_other` 分叉，因为不含 `count`）。
